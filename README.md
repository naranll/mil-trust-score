_HACKMIL 2026 хакатоны төсөл · A browser extension that gives news pages and Facebook posts an explainable 0–100 trust score, then teaches media and information literacy instead of telling users what is true. And a website to promote media literacy for all ages._

## Асуудал

Монголд худал, төөрөгдүүлсэн мэдээлэл голчлон Facebook, мессенжерээр хурдан тардаг. Залуучууд мэдээллийн эх сурвалж, санаа зорилгыг үнэлэх хэрэгсэл, дадалгүй хуваалцдаг.

## Шийдэл

«Итгэлцлийн оноо» нь хуудас бүр дээр 0–100 оноо болон гол 3 шалтгааныг шууд харуулна. Оноо нь кредит скоркарттай ижил зарчмаар, тайлбарлагдахуйц шинж тэмдгүүдэд суурилна:

| Бүлэг        | Юуг шалгах вэ                                                                                                      |
| ------------ | ------------------------------------------------------------------------------------------------------------------ |
| **Домэйн**   | Сайтын нас, алдартай сайтыг дуурайсан нэр, холбоо барих хаяг, HTTPS, бүртгэлтэй хэвлэл мэдээллийн байгууллага эсэх |
| **Текст**    | Clickbait гарчиг, сэтгэл хөдлөл өдөөх үг, эх сурвалж ба ишлэл, нэргүй эх сурвалж, зохиогч ба огноо                 |
| **Контекст** | Хуучин мэдээ дахин тарсан эсэх, зургийг өөр контекстоос авсан эсэх, олон хуудсаар тархсан эсэх                     |
| **Нотолгоо** | Мэдэгдэл итгэмжлэгдсэн эх сурвалж, албан статистиктай таарч байгаа эсэх                                            |

Оноог 3 бүсэд хуваана: 🟢 **70+** · 🟡 **40–69** · 🔴 **40-өөс доош**

> **Хэрэгсэл үнэн, худлыг шийдэхгүй.** Харин залуучуудад мэдээллийг шүүн тунгаах дадлыг өдөр тутмын хэрэглээн дунд нь заана.

## Онцлог

- **Өнгөт badge:** хаягийн мөр болон Facebook пост бүрийн хажууд оноо харагдана.
- **Шалтгаан ба MIL карт:** дарахад гол 3 шалтгаан, тус бүрт 30 секундын MIL карт гарна.
- **Хуваалцахын өмнө түр зогс:** улаан бүсийн пост дээр Share дарахад «Эх сурвалжийг нь шалгасан уу?» гэсэн сануулга гарна. Хэрэглэгч үргэлжлүүлэх эрхтэй.
- **Сургалтын горим:** оноо эхлээд нуугдана. Хэрэглэгч 3 асуултад (эх сурвалж? огноо? хэн ашиг хүртэх вэ?) хариулж өөрөө үнэлсний дараа загварын дүгнэлт гарна.
- **Санал хүсэлт:** «Энэ оноо буруу байна» товч. Хариу нь дараагийн шошготой өгөгдөл болно.

## Backend ажиллуулах

```bash
# repo-ийн үндэс хавтаснаас
python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r backend/requirements.txt
cd backend
uvicorn app.main:app --reload --port 8000
pytest -q
```

## Ёс зүй ба хязгаарлалт

- **Хувийн мэдээлэл:** хэрэглэгчийн нэр, сэтгэгдэл, үзсэн түүхийг цуглуулахгүй, хадгалахгүй.
- **Улс төрийн төвийг сахих:** нам, улс төрчөөр биш, зөвхөн арга барилын шинж тэмдгээр үнэлнэ.
- **False positive:** бодит мэдээллийн сайтыг улаан бүсэд оруулахгүй байх нь хамгийн чухал хэмжүүр.
- **LLM-ийн алдаа:** нотолгоо заавал эх сурвалжийн холбоостой. Нотолгоо олдохгүй бол «шалгах боломжгүй» гэж харуулна.
- **Хэт итгэхээс сэргийлэх:** оноо бүрэн найдвартай биш. Хэрэглэгчид энэ тухай тодорхой хэлнэ.

## Цаашдын төлөвлөгөө

- **0–3 сар:** Хэвлэлийн хүрээлэнтэй хамтран шошготой монгол датасет бүрдүүлж, нээлттэй болгоно.
- **3–6 сар:** Их сургууль, ахлах ангийн MIL хичээлд сургалтын горимыг туршина.
- **6–12 сар:** Messenger бот, OCR, зохион байгуулалттай тархалт илрүүлэх модулийг нэмнэ.
